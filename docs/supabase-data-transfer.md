# SupabaseからPostgreSQLへのデータ移行

- 更新日: 2026-10-11
- 要件 FR-021 / AC-035: 業務データのID、参照関係、金額、日付、状態、設定を移行し、全件照合する。
- 要件 FR-022 / AC-036: 登録ユーザーのID、メール、管理者権限を移行し、既存のデモ管理者を保持する。ユーザーのパスワード再設定が必要な点はユーザー承認済み。
- 設計: 移行元は読み取りのみ。両DBをローカルへバックアップし、移行先への書き込みと照合を単一トランザクションで行う。同じIDの異なる業務データがある場合は停止する。設定のdefault行は移行元の値を反映する。
- 秘密情報と個人データを含むバックアップは `.local-postgres/migrations/` に保存する。Gitには含めない。

## 実行

`.env.local` に旧SupabaseのURLとservice role key、および移行先の `DATABASE_URL` が必要。

```powershell
node --env-file=.env.local scripts/migrate-supabase.mjs --include-users
```

上記は取得とバックアップ、件数表示のみ。実移行には `--apply` を追加する。
既存のユーザーID・メールが衝突した場合は停止し、既存パスワードは変更しない。
新規移行ユーザーにはランダムなパスワードのハッシュを設定し、再設定までログインできないようにする。Supabase側のパスワードとユーザーは変更しない。
再設定メールを使う場合はSMTP設定が必要。
旧 `invoice_items.included` は現行アプリで使わない列のためDBへの取込対象外とし、元の値をバックアップに保持する。
