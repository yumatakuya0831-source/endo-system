## 1. 目的・対象

デモシステムがビルド可能で、主要な見積・請求業務の実装要素と永続化APIが存在し、初期状態を正常表示できることを確認する。

## 2. テスト環境

- OS: Windows
- 実行環境: Node.js / vinext / Vite / CloudflareローカルD1
- 実施日: 2026-09-06
- テストデータ: `app/lib/domain.ts` のデモデータ

## 5. 未実施・残存リスク

- ブラウザ上の全ボタン操作、ドラッグ操作、モバイル実機確認は未実施。
- 認証・認可、監査ログ、バックアップ、負荷試験は未実施であり、本番利用不可。
- `drizzle-kit generate` は実行環境の `uv_os_get_passwd returned ENOMEM` で失敗したため、スキーマと同内容の migration を手動作成した。
- 請求書はデモ仮定の「1見積・1顧客会社・1請求書」。税、合算・分割、入金は未実装。
